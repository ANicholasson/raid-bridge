# Security

raid-bridge has no releases yet, so security fixes land on `main`.

To report a vulnerability, use GitHub's private vulnerability reporting: the Security tab of this repository, then "Report a vulnerability". Please don't open a public issue for it, and don't attach a Snapshot or a memory capture: they hold your account's data.

A vulnerability here includes anything that breaks the promises in the README: raid-bridge opening the game with more than read access, running code inside it or writing to its memory, sending anything over the network, or putting an account id, player name or clan name into a Snapshot.

You get an acknowledgement within a week and a fix or a decision within thirty days.
